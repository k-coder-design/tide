# Tide — plan

A private iPhone app for tracking libido dynamics: partnered sex, other sexual activity (masturbation, sexual dreams, fantasies) and daily desire (1–5). For personal use only, data stays on the device.

| T21 | **App lock as built (phase 3)** — Face ID part removed by T22. Locking closes the in-memory database and clears the key: nothing of the journal stays in memory. Wrong PINs: four free tries, then waits of 30 s, 1 min, 5 min and 15 min, kept across restarts. Turning the lock off asks for the PIN or Face ID and gives the same key back to the browser's keeping. While Tide is off screen a plain cover with the icon replaces the journal, for the app switcher snapshot. ## Web app limits on iPhone (affect phases 3 and 7)

- **Face ID**: no direct API; possible only through a passkey (WebAuthn PRF). Built in v0.3.0 and removed (T22): Tide uses the PIN only.
- **Reminders**: a web app cannot schedule a local notification; Web Push needs a server. Server-free option: an iOS Shortcuts personal automation that shows a neutral notification every evening and opens Tide.
- **Widget**: not possible for a web app. Option: a Shortcut on the Home Screen or Lock Screen that opens Tide straight on "quick add".
- **Removing the Home Screen icon deletes the data** — backups (phase 4) are essential.
