# Tide

A private iPhone app for tracking libido dynamics: partnered sex, other sexual activity and daily desire. A Home Screen web app, data stays on the device. Version 0.0.1 (phase 0 — setup).

Plan: [PLAN.md](PLAN.md). Data model: [docs/DATA_MODEL.md](docs/DATA_MODEL.md). Notes for AI agents: [AGENTS.md](AGENTS.md).

## Running

Needs Node.js 22+.

```bash
npm install
```

```bash
npm run dev
```

| Command | What it does |
| --- | --- |
| `npm run dev` | Development server with hot reload |
| `npm run build` | Static files in `dist/` |
| `npm run preview` | Serve the built app |
| `npm run typecheck` | Type-check |
| `npm test` | Tests (Vitest) |
